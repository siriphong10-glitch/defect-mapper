# Inspect Recorder — บันทึกความเสียหายและผลทดสอบบนแบบแปลน

เว็บแอพสำหรับปักตำแหน่งและบันทึกรายละเอียดความเสียหายของงานตรวจสอบอาคาร/โครงสร้างลงบนแบบแปลน แล้วส่งออกเป็นรายงาน

**เปิดใช้งาน:** https://siriphong10-glitch.github.io/defect-mapper/

## ความสามารถ
- **หน้ารวมโครงการ** แสดงเป็นการ์ด ใส่รูปหน้าปกได้ (ถ้าไม่ใส่จะเป็นการ์ดสีขาว มีขอบบนตามสีที่เลือก)
- **นำเข้าแปลนได้หลายชั้น** รองรับไฟล์ JPG/PNG และ PDF หลายหน้า (1 หน้า = 1 ชั้น)
- **ปักตำแหน่ง** ได้ทั้งแบบจุด พื้นที่หลายเหลี่ยม และสี่เหลี่ยม สีหมุดเปลี่ยนตามระดับความเสียหาย
- **ตั้งสเกลแปลน** จากระยะที่ทราบค่า เพื่อคำนวณพื้นที่ (ตร.ม.) ของบริเวณที่วาดให้อัตโนมัติ
- **แบบฟอร์ม 2 ประเภท**: ตรวจสอบโครงสร้าง (ตามแบบฟอร์มรายงานเดิม) และตรวจสอบทั่วไป แก้ไขหัวข้อ ตัวเลือก และเพิ่มหัวข้อใหม่ได้ที่ “⚙ หัวข้อความเสียหาย”
- **การรันเลขลำดับ** เลือกได้ตอนสร้างโครงการ ว่าจะให้รันอัตโนมัติหรือกำหนดเอง (ระบบเสนอเลขถัดไปให้ และไม่ยอมให้เลขซ้ำกัน)
- **ส่งออก**
  - Word (.docx): ปก (เลือกได้), สรุปจำนวน, แปลนเรียงชั้น, รายการแยกตามหัวข้อ (หัวข้อซ้ำแสดงครั้งเดียว พร้อมรูปตัวอย่าง 1–2 รูป), ตารางตำแหน่งทุกจุด และแบบฟอร์มรายจุด
  - PDF: เนื้อหาเหมือน Word และมีหน้าปก
  - รูปแปลน (.png) ที่ปักตำแหน่งแล้ว
  - Excel (.xlsx): รายการทุกจุด สรุปตามหัวข้อ และสรุปตามชั้น
  - แพ็กข้อมูล (.zip): `report.json` + แปลน + รูป + README สำหรับส่งให้ Claude เขียนรายงานต่อ และใช้สำรอง/ย้ายเครื่องได้ (นำเข้ากลับได้ที่หน้าแรก)

## การเก็บข้อมูล
ข้อมูลทั้งหมด รวมถึงแปลนและรูปถ่าย เก็บอยู่ใน IndexedDB ของเบราว์เซอร์บนเครื่องที่ใช้งาน **ไม่มีการอัปโหลดขึ้นเซิร์ฟเวอร์** จึงควรส่งออก “แพ็กข้อมูล (.zip)” เป็นระยะเพื่อสำรองข้อมูล หรือเมื่อต้องการย้ายไปทำงานต่อบนเครื่องอื่น

## คีย์ลัด
| ปุ่ม | การทำงาน |
|---|---|
| V | เลือก/เลื่อน |

| A | วาดพื้นที่ (Enter = จบ, Backspace = ลบมุมล่าสุด) |
| R | วาดสี่เหลี่ยม |
| S | ตั้งสเกล |
| C | เปิด/ปิด “ใช้รายละเอียดเดิม” |
| L | แสดง/ซ่อนเลขบนแปลน |
| F | พอดีจอ |
| Delete | ลบจุดที่เลือก |
| Esc | ยกเลิก / ปิดแผงรายละเอียด |

## โครงสร้างโค้ด
เป็นเว็บแบบ static (HTML/CSS/JavaScript modules) ไม่ต้อง build ไลบรารีที่ใช้ (docx, SheetJS, JSZip, jsPDF, html2canvas, pdf.js, ฟอนต์ Sarabun) เก็บไว้ในโฟลเดอร์ `vendor/` จึงไม่ต้องพึ่ง CDN

```
index.html
css/app.css
js/app.js          หน้ารวมโครงการ + สร้าง/แก้ไขโครงการ
js/workspace.js    หน้าทำงาน: แปลน, ปักตำแหน่ง, แผงรายละเอียด
js/templates.js    แบบฟอร์มเริ่มต้น (โครงสร้าง / ทั่วไป)
js/tpl-editor.js   หน้าต่างแก้ไขหัวข้อความเสียหาย
js/export.js       ส่งออก Word / PDF / Excel / รูป / แพ็กข้อมูล
js/project.js      ระบบเลขลำดับ และโหลดข้อมูลโครงการ
js/db.js           IndexedDB
```

Deploy อัตโนมัติด้วย GitHub Actions ทุกครั้งที่ push ไปที่ `main`
